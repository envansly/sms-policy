Overview

Eric VanSlyke alerts are informational SMS messages sent only to users who have signed up by texting the opt-in keyword. The program is small; at present the only enrolled user is the operator.

Program description

A script operated by Eric VanSlyke checks a monitored email inbox on a schedule and sends enrolled users a short SMS notification when an item needs a decision, along with occasional status updates. Messages are operational and transactional. No marketing or promotional messages are sent.

How consent is given

Users sign up by texting START to (765) 633-8696 from the mobile phone that should receive alerts. Sign-up instructions and the full disclosure are at https://envansly.github.io/sms-policy/optin.html. A confirmation message is sent on sign-up. There is no other enrollment method.
